# Rinde Fácil: demo

Demostración de la app Rinde Fácil con **datos ficticios**. No es el sitio oficial y no guarda datos reales.

- Lo que se escribe queda solo en el navegador de quien usa la demo. No hay servidor ni base de datos.
- Los comentarios y el servicio en la nube están desconectados en esta versión.
- Para probar, usa un nombre de comunidad de ejemplo y una contraseña de al menos 10 caracteres.

Este repositorio contiene solo el código de la demo: el servicio de Apps Script y las pruebas no se publican aquí.
